# GraphQL Tutorial - Basic Client Server

A basic GraphQL client-server application designed for learning the fundamentals of GraphQL.

## Overview

This project demonstrates the core concepts of GraphQL with a simple client-server architecture. It's a great starting point for anyone looking to understand how GraphQL works and how to build a basic GraphQL API.

## Features

- **GraphQL Server** - A simple GraphQL server implementation
- **GraphQL Client** - Basic client for querying the server
- **Learning-Focused** - Clean, beginner-friendly code structure

## Prerequisites

Before you begin, ensure you have the following installed:
- Node.js (v14 or higher)
- npm or yarn

## Installation

1. Clone the repository:
```bash
git clone https://github.com/shubham168/graphql-tut.git
cd graphql-tut
```

2. Install dependencies:
```bash
npm install
```

## Usage

### Running the Server

```bash
npm run server
```

The server will start and typically listen on `http://localhost:4000`

### Running the Client

In a new terminal window:

```bash
npm run client
```
